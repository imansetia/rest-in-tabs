Regex matches nothing

Asked four years ago · viewed 2,318 times · 3 answers

This pattern should match dates such as 2021-04-09, but it matches nothing, not even a line that holds only a date.

^\d{4}-\d{2}-\d{2}$

The input is read from a file, one date per line.

3 answers

The lines probably end in a carriage return. Try ^\d{4}-\d{2}-\d{2}\r?$.

2 votes

Without the multiline flag, ^ and $ match the start and end of the whole file, not of each line.

1 vote

Check that the backslashes survive when the pattern is written as a string in the code.
