# Product: Rest in Tabs

Browser extension that "buries" idle tabs in a spooky graveyard so the browser stays fast, and lets the user "resurrect" any of them in one click.

## Problem
People keep dozens of tabs open "for later". Tabs eat memory and attention, but closing them feels like losing information.

## Audience
Students, researchers and developers who hoard tabs (20+ open at once).

## Core promise
- Nothing is lost: every buried tab can be resurrected with its URL, title and a short summary.
- The browser gets lighter automatically.
- The graveyard is fun to visit, never confusing.

## Hackathon context
- Kiroween 2026, category **Costume Contest**: the haunting UI must serve the function (tombstone = saved tab, decay = age, resurrect = reopen).
- All user-facing text and docs are in English.
- Judges value: real impact, deep Kiro usage, polished design, clear 3-minute demo.

## Tone
Playful-spooky, never gory. Copy is short. The dry humour lives in the cause of death; the epitaph is the page's own factual summary; buttons and errors stay plain (see the Copy rules in design.md).
